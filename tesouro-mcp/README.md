# Conector MCP – Preços do Tesouro Direto

Ferramenta única: `precos_tesouro` — taxa e PU de resgate dos títulos do Tesouro Direto.

- Fonte principal: página "Rendimento dos Títulos" (aba Resgatar) do Tesouro Direto.
- Reserva automática: CSV oficial do Tesouro Transparente (PU de venda da manhã do último dia).

Endpoint após o deploy na Vercel: `https://SEU-PROJETO.vercel.app/api/mcp`
